Über mich

Mein Name ist Onurcan Ünsal. Ich bin ein 24-jähriger Entwickler. Nach meinem Abitur habe ich mich für das Informatikstudium an der Universität Augsburg entschieden.
Die Jahre während meines Studiums haben mich positiv geprägt. Nicht nur das gemeinsame Programmieren mit den Freunden, sondern auch das Besuchen von verschiedenen Vorlesungen hat mir sehr viel Freude erbracht. Die Verwendung von Analysis und Stochastik hat ebenfalls dazu beigetragen. In den Vorlesungen habe ich unter anderem die Programmiersprachen C, C#, Java, Python und SQL erlernt.

Buchungssystem (ASP.NET)

Eine Prüfung des Studiums ist ein größeres Softwareprojekt. Das wurde in einem zufällig ausgelosten Team absolviert. Dabei sollte ein Buchungssystem für E-Fahrzeuge erstellt werden, die Ladestationen für ihr Fahrzeug reserviert haben.
Das Ziel des Projekts ist die Vermittlung eines methodischen Vorgehens beim Software-Entiwicklungs-Prozess. Dazu werden die verschiedenen Phasen (wie z.B. Analyse, Design, Implementierung, Testen, Abnahme) durchlaufen.

Simulation eines Produktionsablaufes (AnyLogic/Java)

Die Ziel der Bachelorarbeit war die Erstellung einer Simulation mit dem Simulationsframework AnyLogic. Um eine komplexe Simulation zu erstellen wird diese mit der Programmiersprache Java erstellt. Durch die Implementation einer Datenbank konnten verschiedene Aufträge simuliert werden.

Graph Neural Netorks (GNNs)

In dieser Arbeit handelte es sich um Untersuchung von GNNs. Durch die Anwendung von Graph Neural Networks werden in vielen Bereichen des Machine Learnings deutlich bessere Ergebnisse erzielt, als die dafur verwendeten state-of-the-art Methoden. Diese werden in der Physik, Chemie, Biologie, Empfehlungssystemen und der Verarbeitung von Texten und Bildern angewendet.

Twitter-Analyse (Python/PySpark)

In der Forschungsarbeit findet eine Twitter-Analyse der Fussball-WM 2014 statt. Die Arbeit wurde in Pyhon geschrieben. Die dafür verwendeten Bibliotheken waren PySpark, pandas, os, sys, preprocessor und textblob. Am Ende der Arbeit fand eine Analyse der erarbeiteten Werte statt.
